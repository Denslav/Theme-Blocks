# Changelog

All notable changes to Theme Blocks are documented in this file.

## [1.1.2] - 2026-07-24

### Added

- Plugin license metadata and author URL.
- Runtime constants for the plugin version and base path.
- Duplicate protection for the custom block category.
- PHP syntax checking utility.
- JavaScript, SCSS and combined lint scripts.
- Formatting, release build and plugin ZIP commands.
- Release file allowlist in `package.json`.
- `README.md`, WordPress `readme.txt`, GPL license and third-party notices.
- Translation POT template.
- Repository housekeeping files.

### Changed

- Improved validation when scanning and registering block directories.
- Updated the plugin infrastructure version to 1.1.2.

### Unchanged

- The Test Block source code.
- The Test Block metadata and PHP renderer.
- The compiled Test Block JavaScript and CSS assets.

## [1.1.1]

- Previous plugin release.
